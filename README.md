## ALGORITMO
Un algoritmo es un conjunto ordenado de pasos o instrucciones que se siguen para resolver un problema o realizar una tarea específica.

Características principales de un algoritmo:

Preciso: cada paso debe ser claro y sin ambigüedades.

Ordenado: los pasos se ejecutan en un orden determinado.

Finito: debe tener un inicio y un final.

Eficiente: debe resolver el problema en el menor tiempo y con los menores recursos posibles.

Entrada y salida: recibe datos (entrada) y produce un resultado (salida).

Ejemplo sencillo (hacer un café)

Calentar agua.

Poner café en el filtro.

Verter el agua caliente sobre el café.

Servir el café en una taza.
